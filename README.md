**DSA-Mastery: Complete Java Solutions & Algorithmic Patterns**

**DSA-Mastery** serves as a centralized, high-standard repository documenting my technical problem-solving journey across core Data Structures and Algorithms, implemented exclusively in **Java**.

Every solution prioritizes industry-grade code quality, optimal runtime and space efficiency, and clear step-by-step intuition to bridge the gap between competitive coding and technical interview standards.

---

**Core Focus & Highlights**

* **Strictly Java-Centric:** Idiomatic Java code leveraging clean object-oriented design, robust edge-case handling, and modern standard library utilities.
* **Complexity-Driven:** Every solution is engineered for peak performance, minimizing overhead with detailed time ($O(1)$, $O(\log n)$, $O(n)$) and space ($O(1)$, $O(n)$) complexity breakdowns.
* **Structured & Scannable:** Organized methodically by data structure, algorithmic pattern, and problem difficulty (Easy, Medium, Hard).
* **Interview-Ready Documentation:** Includes core intuition, brute-force to optimal progression, and key takeaway notes for rapid revision.

---

**Curated Topic Coverage**

* **Linear Structures:** Arrays, Strings, Two Pointers, Sliding Window, Linked Lists, Stacks, and Queues.
* **Non-Linear & Hierarchical:** Binary Trees, Binary Search Trees (BST), Heaps / Priority Queues, Tries, and Disjoint Set Union (DSU).
* **Advanced Algorithms:** Graph Traversals (BFS, DFS, Dijkstra, Topo-Sort), Dynamic Programming (1D, 2D, Knapsack, Subsequences), Backtracking, Greedy, and Divide & Conquer.
